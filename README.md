One image that sums up the world's news of Saturday 21 November 2026: a
dense newsroom dashboard with a date-locked header, a dotted world map with
13 numbered pins, a UTC strip, and a 7×6 grid of 42 dated cards — 13
verified stories split into sub-facts (event, impact, status/claim), each
carrying an epistemic tag ([RESMI] / [KLAIM] / [DENY] / [2 SUMBER] / [DATA]),
plus 3 summary cards. No fact, timestamp, outlet name, or confidence number
is invented: every card traces to one of the 13 verified stories.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, Pillow + DejaVu fonts shipped in `fonts/`) renders
`entry.png` (1024×1024, ≤ 1 MiB) deterministically: same bytes on every run,
no randomness, no clock, no network.
